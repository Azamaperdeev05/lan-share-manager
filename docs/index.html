Win + R арқылы ортақ папканы лезде ашыңыз.

Көрші немесе кеңседегі кез келген Windows компьютерінен ортақ файлдарға 3 қарапайым қадаммен қосылыңыз.

1
⊞ Win + R

Пернетақтаны басыңыз

Басқа компьютерде Win + R басыңыз — Windows-тың «Выполнить / Run» командалық терезесі ашылады.

2
UNC Network Path

Жолды көшіріп қойыңыз

Ұсынылатын IP мекенжай жолын енгізіңіз. IP арқылы Windows желілік атауды кідіріссіз 100% ашады.

\\192.168.1.100\OBSHAYA
3
↵ Enter

Enter басыңыз

«ОК» немесе Enter басыңыз — ортақ папка Проводник (Explorer) терезесінде бірден ашылады!

🏃 Выполнить (Run)
✕

Введите имя программы, папки, документа или ресурса Интернета, которые требуется открыть.

\\192.168.1.100\OBSHAYA

Тұрақты диск (Z:) ретінде бекіту

Басқа компьютердің CMD терезесінде мына пәрменді 1 рет орындасаңыз, папка диск болып сақталып қалады:

net use Z: \\192.168.1.100\OBSHAYA /persistent:yes

Ортақ қатынас сәтті бапталды.

Енді кез келген компьютер мына сілтемелер арқылы кіре алады:

СЕТЕВОЙ ПУТЬ: \\DESKTOP-MKVG1ET\OBSHAYA

10-деңгейлі кешенді авто-диагностика:

[✓] 1. LanmanServer SMB қызметінің статусы Іске қосылған (Running)
[✓] 2. TCP 445 портының тыңдалуы (Listener) Белсенді (Listening)
[✓] 3. Windows Firewall ережесі (Inbound 445) Рұқсат берілген (Private)
[✓] 4. NTFS Security рұқсаттары (ACL) Үйлестірілген
[✓] 5. Локалды пинг \\localhost\OBSHAYA Қолжетімді
[✓] 6. LAN IP пингі \\192.168.1.100\OBSHAYA Қолжетімді (1ms)

Қолмен баптау мен LAN Share Manager айырмашылығы.

Windows-тың стандартты ортақ ету жолы неліктен қатеге толы және біз оны қалай 3 секундқа түсірдік?

Стандартты Windows Қолмен 15 қадам
  • ✕ Шатастыратын 15 терезе: Папка қасиеттері ➔ Доступ ➔ Безопасность ➔ Дополнительно ➔ Өзгерту.
  • ✕ NTFS қателіктері: Тек SMB рұқсатын ашып, файлдық NTFS құқығын ұмытып кетеді ➔ "Access Denied" қатесі шығады.
  • ✕ Брандмауэрді өшіріп тастау: 445 портын білмегендіктен адамдар антивирусты толық сөндіріп, вирус жұқтырады.
  • ✕ Public Network қаупі: Егер желі кездейсоқ "Общедоступная" болса, компьютерлер бірін-бірі мүлдем көрмейді.
LAN Share Manager Ұсынылған ✓
  • ✓ Барлығы 1 батырмада: Папканы таңдайсыз, ат бересіз және басасыз. Барлық баптау 3 секундта бітеді.
  • ✓ Синхронды SMB + NTFS: Қос деңгейлі құқықтар бірден толық үйлесімділікпен жазылады.
  • ✓ Қауіпсіз Брандмауэр: Брандмауэр сөндірілмейді! Тек TCP 445 порты Private профиль үшін қауіпсіз ашылады.
  • ✓ Дайын сілтемелер: Басқа компьютерге жіберетін \\ПК\SHARE және \\IP\SHARE жолдары бірден көшіріледі.

Ең аз артықшылық принципі

SMB және NTFS рұқсаттары толық үйлестіріледі. SYSTEM және Әкімші құқықтары сенімді қорғалған.

🛡

Қауіпсіз Брандмауэр

Брандмауэр сөндірілмейді! Тек TCP 445 порты Private профиль үшін арнайы ашылады.

🩺

10-деңгейлі диагностика

Служба күйі, порт ашықтығы, брандмауэр және кері байланыс UNC жолдары автоматты түрде тексеріледі.

💡
