[✓] 2. TCP 445 портының тыңдалуы (Listener) Белсенді (Listening)
[✓] 3. Windows Firewall ережесі (Inbound 445) Рұқсат берілген (Private)
[✓] 4. NTFS Security рұқсаттары (ACL) Үйлестірілген
[✓] 5. Локалды пинг \\localhost\OBSHAYA Қолжетімді
[✓] 6. LAN IP пингі \\192.168.1.100\OBSHAYA Қолжетімді

Қолмен баптау мен LAN Share Manager айырмашылығы.

Windows-тың стандартты ортақ ету жолы неліктен қатеге толы және біз оны қалай 3 секундқа түсірдік?

Стандартты Windows Қолмен 15 қадам
  • ✕ Шатастыратын 15 терезе: Папка қасиеттері ➔ Доступ ➔ Безопасность ➔ Дополнительно ➔ Өзгерту.
  • ✕ NTFS қателіктері: Тек SMB рұқсатын ашып, файлдық NTFS құқығын ұмытып кетеді ➔ "Access Denied" қатесі шығады.
  • ✕ Брандмауэрді өшіріп тастау: 445 портын білмегендіктен адамдар антивирусты толық сөндіріп, вирус жұқтырады.
  • ✕ Public Network қаупі: Егер желі кездейсоқ "Общедоступная" болса, компьютерлер бірін-бірі мүлдем көрмейді.
LAN Share Manager Ұсынылған
  • ✓ Барлығы 1 батырмада: Папканы таңдайсыз, ат бересіз және басасыз. Барлық баптау 3 секундта бітеді.
  • ✓ Синхронды SMB + NTFS: Қос деңгейлі құқықтар бірден толық үйлесімділікпен жазылады.
  • ✓ Қауіпсіз Брандмауэр: Брандмауэр сөндірілмейді! Тек TCP 445 порты Private профиль үшін қауіпсіз ашылады.
  • ✓ Дайын сілтемелер: Басқа компьютерге жіберетін \\ПК\SHARE және \\IP\SHARE жолдары бірден көшіріледі.

Негізгі мүмкіндіктер мен архитектура.

🔒

Least Privilege.

ReadOnly немесе ReadWrite таңдалса, дәл сол минималды қажетті рұқсат қана беріледі. Ешқашан артық құқық ашылмайды.

🛡

Қауіпсіз Брандмауэр.

Кездейсоқ порттар ашылмайды. Ереже тек Private желі профиліне бекітіледі. Жүйе қауіпсіздігі 100% сақталады.

🩺

10-деңгейлі Диагностика.

LanmanServer қызметінен бастап, нақты UNC path-қа дейін автоматты тексереді. Қате болса, нақты шешімін айтады.

💾

Нөлдік дерек жоғалуы.

Ортақ папканы өшіргенде (Remove Share), дискідегі файлдар ешқашан өшпейді. Тек SMB желілік тіркеуі ғана алынады.

🔄

100% Идемпотенттілік.

Бірнеше рет қатарынан іске қосқанмен де конфигурация дубликатталмайды және файлдық жүйе бұзылмайды.

⚡

JSON Экспорт & Импорт.

Барлық баптауларды бір JSON файлына көшіріп, жаңа компьютерге немесе жаңа Windows орнатқанда лезде импорттаңыз.
