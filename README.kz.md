## 🌟 Неліктен LAN Share Manager қажет?

Windows жүйесінде папканы жергілікті желіге ашу үшін көптеген күрделі қадамдарды қолмен жасау керек болады:
1. Папканың «Свойства» терезесін ашып, «Доступ» қосымшасына өту.
2. SMB Share Permissions құқықтарын баптау.
3. «Безопасность» қосымшасына өтіп, NTFS ACL тізімдері мен мұрагерлік (inheritance) жалаушаларын қолмен реттеу.
4. Windows брандмауэрінен TCP 445 порты мен «Файлдар мен принтерлермен ортақ пайдалану» ережелерін табу.
5. Желі түрін тексеру («Общедоступная / Public» күйінен «Частная / Private» күйіне ауыстыру).
6. Компьютердің желілік IPv4 мекенжайын және атауын білу.
7. Басқа компьютерлерден байланыс бар-жоғын тексеру.

**LAN Share Manager осының барлығын автоматты түрде 1 шертумен орындайды.**

```text
[ Папканы таңдау ] ➔ [ Ресурс атауы ] ➔ [ Қолжетімділік деңгейі ] ➔ [ 1-шертумен ашу ]
        │
        ├── 1. Жолды тексеру және қажет болса папканы автоматты құру
        ├── 2. NTFS ACL құқықтарын реттеу (барлық ішкі папкаларға мұрагерлік)
        ├── 3. SMB ортақ ресурсын тіркеу (Native Windows CIM / PowerShell)
        ├── 4. Брандмауэр ережесін қосу (TCP 445 тек Private желі үшін)
        ├── 5. Компьютердің LAN IPv4 мекенжайы мен атауын анықтау
        ├── 6. 10-деңгейлі кешенді автоматты диагностика
        └── 7. Дайын Win + R көшірме жолдары (\\IP\Share және \\Hostname\Share)
```

## 💡 Басқа компьютерден қалай қосылу керек? (`Win + R`)

Көрші немесе кеңседегі басқа компьютерден ортақ папкаға қосылу үшін ең ыңғайлы тәсіл:

```text
┌────────────────────────────────────────────────────────────────────────┐
│  Выполнить (Run)                                                  [X]  │
├────────────────────────────────────────────────────────────────────────┤
│  Введите имя программы, папки, документа или ресурса Интернета...      │
│                                                                        │
│  Открыть: [ \\192.168.1.55\Baza                              ▼]        │
│                                                                        │
│               [  OK  ]          [ Отмена ]          [ Обзор... ]       │
└────────────────────────────────────────────────────────────────────────┘
```

### Қадам-қадаммен нұсқаулық:

1. **1-қадам:** Басқа компьютердің пернетақтасынан бір уақытта **`Win + R`** түймелерін басыңыз (Windows-тың «Выполнить / Орындау» терезесі ашылады).
2. **2-қадам:** Ашылған жолға мына желілік UNC жолды енгізіңіз:
   ```cmd
   \\192.168.X.X\ПапкаАтауы
   ```
   *(Мысалы: `\\192.168.1.55\Baza` немесе `\\192.168.1.55\SharedFolder`)*

   > **💡 Неге IP мекенжай ұсынылады?**  
   > Компьютер атауымен (`\\DESKTOP-ABC\Baza`) де қосылуға болады. Бірақ кейде желіде Windows атауды табу кезінде (mDNS/NetBIOS) кідіріп қалады. Ал **IP арқылы папка бірден, ешқандай кідіріссіз 100% ашылады**.

3. **3-қадам:** **`Enter`** (немесе «ОК») басыңыз. Папка «Проводник» терезесінде бірден ашылады!

### Қосымша кеңестер:

* **Логин мен пароль сұралса:**  
  Егер Windows басқа компьютерде «Ввод сетевых учетных данных» терезесін шығарса:
  * **Пайдаланушы аты:** `.\Пайдаланушы` (мысалы `.\Admin` немесе `.\Azamat`)
  * **Құпиясөз:** Папканы ашқан негізгі компьютердің Windows паролі.
* **Тұрақты диск (Z:) етіп бекіту:**  
  Әр жолы код теріп жүрмеу үшін басқа компьютердің командная строкасына (CMD) мына пәрменді 1 рет енгізіңіз:
  ```cmd
  net use Z: \\192.168.X.X\ПапкаАтауы /persistent:yes
  ```

## 💎 Негізгі мүмкіндіктер

* 🌐 **Толық 3 тілді қолдау:** Қазақша (🇰🇿), Русский (🇷🇺) және English (🇬🇧) арасында лезде ауысу.
* ⚡ **1 шертумен ортақ папка құру:** Дайын UNC сілтемелерін 1 басу арқылы көшіру.
* 🔒 **Ең аз артықшылық принципі (Least Privilege):**
  * **Тек оқу (Read Only):** `Everyone` → Read (SMB) және Read & Execute (NTFS).
  * **Оқу және жазу (Read & Write):** `Everyone` → Change (SMB) және Modify (NTFS).
  * **Толық қолжетімділік (Full Control):** `Everyone` → Full (SMB) және Full Control (NTFS).
* 🛡️ **Жүйелік құқықтар қорғалған:** `SYSTEM`, `Administrators` және каталог иесінің құқықтары өзгеріссіз сақталады.
* 🔥 **Брандмауэр қауіпсіздігі:** TCP 445 порты **тек Private (Частная сеть) желісі үшін** ашылады.
* 🩺 **10 деңгейлі кешенді диагностика:** `LanmanServer` қызметі, 445 порты, брандмауэр ережелері және `\\IP`, `\\Hostname` байланысы толық тексеріледі.
* 💡 **Қателерді автоматты түзеу шебері (Remediation Advisor):** Қате орын алса, оның себебі мен 1 шертумен жөндейтін нақты батырмасын ұсынады.
* 💾 **Деректердің жоғалмауы:** Ортақ ресурсты желіден өшірген кезде **дискідегі нақты файлдар өшірілмейді**.
* 📦 **JSON көшірме жасау:** Барлық ортақ папкаларды 1 файлға сақтау және қайта қалпына келтіру.

## ⌨️ Терминал пәрмендері (CLI)

```cmd
# Жаңа ортақ папка құру
LANShareManager.exe create --path "C:\OBSHAYA" --name "OBSHAYA" --access readwrite

# Барлық ортақ папкалар тізімін көру
LANShareManager.exe list

# Папканың желілік байланысын диагностикалау
LANShareManager.exe test --name "OBSHAYA"

# Ортақ папканы желіден өшіру (файлдар дискіде қалады)
LANShareManager.exe remove --name "OBSHAYA"

# Желі мен брандмауэрді автоматты жөндеу
LANShareManager.exe autofix

# Барлық баптауларды JSON файлына сақтау
LANShareManager.exe backup --export "shares.json"
```
