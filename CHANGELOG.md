# История изменений (Changelog)

Все заметные изменения проекта фиксируются в этом файле.

## [1.0.0] — 2026-09-23

### Добавлено
- Полнофункциональный графический интерфейс (GUI) на WPF (.NET 8 Windows) с темой Windows 11 Fluent Design.
- Консольная утилита (CLI) `LANShareManager.exe` с поддержкой автоматизации (`create`, `list`, `test`, `remove`, `export`, `import`, `gui`).
- Автоматическая настройка прав безопасности NTFS через `System.Security.AccessControl` с наследованием на подкаталоги и файлы.
- Создание и управление общими ресурсами SMB (Server Message Block) с сохранением принципа наименьших привилегий.
- 3 режима доступа: «Только чтение», «Чтение и запись», «Полный доступ».
- Автоматическая конфигурация Брандмауэра Windows для входящего SMB трафика (TCP 445) строго для профиля Private.
- Автоопределение сетевых параметров (компьютер, активный сетевой адаптер, LAN IPv4, профиль сети).
- 10-точечная система диагностики с выводом рекомендаций по устранению проблем.
- Защита данных: удаление сетевого ресурса никогда не затрагивает локальные файлы.
- Идемпотентность всех операций создания и изменения.
- UAC манифест приложения (`requireAdministrator`) с PerMonitorV2 DPI.
- 36 xUnit модульных тестов с 100% прохождением.
