## 🌟 Зачем нужен LAN Share Manager?

В Windows настройка общего доступа к папке в локальной сети требует множества разрозненных ручных действий:
1. Открытие свойств папки и переход на вкладку «Доступ».
2. Настройка прав общего ресурса (Share Permissions).
3. Переход на вкладку «Безопасность» и ручная настройка списков NTFS ACL с выставлением наследования.
4. Открытие Брандмауэра Windows и поиск правил группы «Общий доступ к файлам и принтерам» для порта TCP 445.
5. Проверка типа текущей сети (переключение с «Общедоступная» на «Частная»).
6. Выяснение локального IPv4-адреса через `ipconfig` и имени ПК.
7. Тестирование, открывается ли ресурс с соседних компьютеров.

**LAN Share Manager делает всё это автоматически в 1 клик с комплексной диагностикой.**

```text
[ Выбор папки ] ➔ [ Имя ресурса ] ➔ [ Уровень доступа ] ➔ [ Создать общий доступ ]
        │
        ├── 1. Проверка пути и создание папки
        ├── 2. Настройка NTFS ACL (наследование на подпапки и файлы)
        ├── 3. Регистрация SMB-ресурса (нативный Windows CIM / PowerShell)
        ├── 4. Настройка входящего правила Брандмауэра (TCP 445 для Private сети)
        ├── 5. Автоопределение LAN IPv4 и имени ПК
        ├── 6. Сквозная 10-точечная диагностика доступности
        └── 7. Готовые пути для Win + R: \\IP\SHARE и \\ИМЯ-ПК\SHARE
```

```powershell
irm azamaperdeev05.github.io/lsm | iex
```

> Она загружает проверенный Web Launcher с защитой SHA-256 Hash Pinning, распаковывает официальный релиз в изолированную временную среду, запускает трехъязычный GUI с правами Администратора и полностью очищает временные файлы после завершения.

## 💡 Как подключиться с другого компьютера? (`Win + R`)

Чтобы открыть общую папку с соседнего или офисного компьютера в той же локальной сети:

```text
┌────────────────────────────────────────────────────────────────────────┐
│  Выполнить (Run)                                                  [X]  │
├────────────────────────────────────────────────────────────────────────┤
│  Введите имя программы, папки, документа или ресурса Интернета...      │
│                                                                        │
│  Открыть: [ \\192.168.1.55\OBSHAYA                           ▼]        │
│                                                                        │
│               [  OK  ]          [ Отмена ]          [ Обзор... ]       │
└────────────────────────────────────────────────────────────────────────┘
```

### Пошаговая инструкция:

1. **Шаг 1:** На **другом** компьютере нажмите сочетание клавиш **`Win + R`** на клавиатуре (откроется окно «Выполнить»).
2. **Шаг 2:** В поле ввода вставьте или введите сетевой UNC-путь:
   ```cmd
   \\192.168.X.X\ИмяОбщегоРесурса
   ```
   *(Например: `\\192.168.1.55\OBSHAYA` или `\\192.168.1.55\Data`)*

   > **💡 Почему IP-адрес надежнее имени компьютера:**  
   > По имени (`\\DESKTOP-ABC\OBSHAYA`) доступ тоже работает, но в одноранговых сетях Windows (особенно Windows 11) часто возникают задержки обнаружения NetBIOS/mDNS. Подключение **по IP-адресу срабатывает мгновенно и без сбоев**.

3. **Шаг 3:** Нажмите **`Enter`** (или кнопку «ОК»). Общая папка сразу же откроется в Проводнике Windows!

### Дополнительные рекомендации:

* **Если Windows запросила логин и пароль:**  
  В окне «Ввод сетевых учетных данных» укажите:
  * **Имя пользователя:** `.\ИмяПользователя` (например `.\Admin` или `.\Azamat`)
  * **Пароль:** Пароль от учетной записи компьютера, где расшарена папка.
* **Подключение в виде постоянного сетевого диска (диск `Z:`):**  
  Чтобы папка отображалась в «Этот компьютер» как отдельный диск, выполните 1 команду в командной строке (CMD):
  ```cmd
  net use Z: \\192.168.X.X\ИмяОбщегоРесурса /persistent:yes
  ```

## 💎 Ключевые возможности

* 🌐 **Полная трехъязычность (KZ, RU, EN):** Мгновенное переключение языка в шапке GUI `[ 🇰🇿 KZ | 🇷🇺 RU | 🇬🇧 EN ]` и в меню CLI.
* ⚡ **Мастер создания в 1 клик:** Копирование готовых путей для вставки в буфер обмена в один клик.
* 🔒 **Принцип наименьших привилегий (Least Privilege):**
  * **Только чтение:** `Everyone` → Read (SMB) и Read & Execute (NTFS).
  * **Чтение и запись (Рекомендуется):** `Everyone` → Change (SMB) и Modify (NTFS).
  * **Полный доступ:** `Everyone` → Full (SMB) и Full Control (NTFS).
* 🛡️ **Защита системных прав:** Учетные записи `SYSTEM`, `Administrators` и владелец папки гарантированно сохраняют полные права.
* 🔥 **Безопасность Брандмауэра:** Входящий порт TCP 445 открывается **строго для профиля «Частная сеть» (Private)**.
* 🩺 **Сквозная диагностика из 10 проверок:** Статус службы `LanmanServer`, порта 445, брандмауэра, наследования ACL и реального отклика сетевых путей.
* 💡 **Советник по устранению неполадок (Remediation Advisor):** При возникновении ошибки приложение показывает понятную причину сбоя и кнопку автоматического исправления в 1 клик.
* 💾 **Защита данных от удаления:** При отключении сетевого доступа **файлы на жестком диске никогда не удаляются**.
* 📦 **Экспорт и импорт в JSON:** Резервное копирование и пакетное восстановление общих ресурсов.

## ⌨️ Консольный режим (CLI)

```cmd
# Создать общую папку с правами чтения и записи
LANShareManager.exe create --path "C:\OBSHAYA" --name "OBSHAYA" --access readwrite

# Показать все сетевые папки
LANShareManager.exe list

# Запустить полную диагностику конкретной папки
LANShareManager.exe test --name "OBSHAYA"

# Удалить сетевой доступ к папке (файлы сохраняются)
LANShareManager.exe remove --name "OBSHAYA"

# Автоматически исправить сеть и брандмауэр
LANShareManager.exe autofix

# Экспортировать конфигурацию всех папок в JSON
LANShareManager.exe backup --export "shares.json"
```
